# PID 控制实验室 · PID Lab

在浏览器里交互式地调 PID：拖动 Kp / Ki / Kd，实时看到被控对象的动画、闭环响应曲线，以及 P、I、D 三个分量各自出了多少力。

**Live**: https://l67077955-cyber.github.io/vibe-coding-showcase/pid-lab/

## 五个被控对象

| 对象 | 特点 | 适合观察 |
|---|---|---|
| 🚗 小车定位 | 质量 + 粘滞阻尼 | P / D 对响应速度与超调的影响 |
| 🚁 无人机高度 | 要持续抵消重力，推力 0–30 N | 积分项如何"托住"飞机；积分饱和 |
| 💧 水箱液位 | 出水 ∝ √液位，非线性 | 一阶系统、PI 控制 |
| 🔥 加热炉温度 | 一阶惯性 + 2 s 纯滞后 | 滞后系统为何容易振荡 |
| 🤸 倒立摆 | 开环不稳定 | D 项提供阻尼；控制周期过长导致失稳 |

每个对象都有「仅 P / PI / PD / PID / 振荡」五组预设，点击后重新做一次阶跃，方便横向比较。

## 功能

- 实时曲线：设定值 vs 测量值；控制量 u 与 P / I / D 分量（含执行器上下限），悬停查看任意时刻的数值
- 诊断栏：实时说明为什么没到目标（缺积分项时需要持续输出多少、执行器饱和、振荡）以及该怎么调
- 响应指标：上升时间（10→90%）、超调量、±2% 调节时间、当前误差、误差积分 IAE
- 控制器细节开关：积分抗饱和（clamping）、微分先行（对测量值求导）、微分一阶低通滤波 T<sub>f</sub>、离散控制周期 T<sub>s</sub>、测量噪声
- 点击画面设置目标（倒立摆为"推一下"），「扰动」按钮施加外部冲击，方波设定值自动来回切换
- 仿真速度 0.25×–4×，浅色 / 深色主题，手机可用

## 操作

| 操作 | 键位 |
|---|---|
| 暂停 / 继续 | 空格 |
| 重置 | R |
| 扰动 | D |

## 技术说明

- 单文件 `index.html`，零依赖、零外部资源，离线可用
- 物理仿真步长 1 ms（半隐式欧拉法）；控制器按 T<sub>s</sub> 离散执行，输出零阶保持
- 离散 PID：`u = Kp·e + Σ Ki·e·Ts + Kd·D_f`，其中 D_f 为一阶低通滤波后的微分；执行器始终按物理上下限饱和
- 所有动画和图表都用 Canvas 2D 手绘
